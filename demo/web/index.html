GPT from Scratch

A decoder-only Transformer written from scratch in PyTorch and trained on TinyStories, running entirely in your browser with ONNX Runtime Web. Nothing is sent to a server.

  • 4.8M parameters
  • 6 layers · 8 heads · dmodel 256
  • character-level · context 128
  • validation loss 0.644
Temperature 0 is greedy decoding; higher values add variety. The model only knows the ~110 characters it was trained on, so other characters in the prompt are dropped.
